- The intended installable Android output is APK first, using the existing `npm run android:apk:installable` script. AAB can be produced after APK succeeds.
- The intended macOS output is the standard Tauri macOS bundle/DMG generated by `npx tauri build`.
- App version remains `0.1.0` unless the human requests a release version bump.
- Android signing can use the existing local script defaults unless production signing credentials are provided.

## Risks

- Android packaging is currently blocked until the local Android SDK components are installed or made visible through environment variables.
- The local branch being behind one upstream commit can cause duplicate work or conflicts; synchronize before implementation.
- Tauri `2.11.0` updates a sizable Rust transitive graph; Cargo lock changes must be reviewed carefully.
- Existing Android signing script creates a local default keystore if no production keystore env vars are set. That is fine for installable QA builds, not for production distribution.
- `frontend/scripts/install-macos-app.sh` uses `rm -rf` and `/Applications`; do not run it without explicit human approval. Packaging does not require installation.

- [ ] Implement `frontend/scripts/check-tauri-client-config.mjs`.

```js
export function validateTauriClientConfig({ packageJson, cargoToml, tauriConfig, androidConfig, capability }) {
  const api = packageJson.dependencies?.["@tauri-apps/api"];
  const cli = packageJson.devDependencies?.["@tauri-apps/cli"];
  const tauri = cargoToml.match(/^tauri = \{ version = "([^"]+)"/m)?.[1];
  const tauriBuild = cargoToml.match(/^tauri-build = \{ version = "([^"]+)"/m)?.[1];

  if (api !== "^2.11.0") throw new Error(`@tauri-apps/api must be ^2.11.0, got ${api}`);
  if (cli !== "^2.11.0") throw new Error(`@tauri-apps/cli must be ^2.11.0, got ${cli}`);
  if (tauri !== "2.11.0") throw new Error(`tauri crate must be 2.11.0, got ${tauri}`);
  if (tauriBuild !== "2.6.0") throw new Error(`tauri-build crate must be 2.6.0, got ${tauriBuild}`);
  if (!tauriConfig.app?.security?.capabilities?.includes("default")) throw new Error("desktop capability default missing");
  if (androidConfig.identifier !== "com.uploaddownloadutil.mobile") throw new Error("android identifier changed");
  if (!capability.permissions?.includes("core:default")) throw new Error("core:default capability missing");

  return { api, cli, tauri, tauriBuild };
}
```
